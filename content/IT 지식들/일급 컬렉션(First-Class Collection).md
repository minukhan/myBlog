
### 일급 컬렉션이란??

- **일급 컬렉션(First-class Collection)**은 “그냥 `List<>`나 `Set<>` 같은 컬렉션을 **그 자체로 하나의 도메인 객체**로 만든 것"

- 그래서 “그 안에 들어있는 여러 개의 값들”에 대해 **규칙·계산·조회·변환 같은 동작을 묶어서** 제공

- 해당 클래스에서 컬렉션과 관련된 비즈니스 로직을 관리하는 패턴을 말함.

### 이걸 사용하는 이유는??

- 일급 컬렉션 클래스에 로직을 포함하거나, 명확한 이름을 부여할 수 있다. 
- 불필요한 컬렉션 API를 외부로 노출 안할 수 있음. 


### 언제 쓰면 딱일까??

- 목록 자체가 도메인 의미를 가질 때.
- 목록에 규칙이 있을 때
- 목록을 가지고 자주 계산, 검색, 변환할 때


> 일급 컬렉션은 “로직을 미리 모아두는 것”이 아니라, “컬렉션 자체를 ‘규칙이 보장되는 타입’으로 만드는 것”이에요.  
   즉, **잘못된 상태를 원천 차단**하고, **변경을 한 곳에서 흡수**하며, **의도를 코드에 드러내기** 위한 설계 기법이에요.
