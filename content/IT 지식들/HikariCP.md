
- 자바 에서 가장 널리 쓰이는 고성능 JDBC 커넥션 풀 라이브러리.
- Hikari ( 빛, 일본어 ) + CP( Connection Pool ) -> 빛처럼 빠른 커넥션 풀
- java 애플리케이션에서 DB 연결을 효율적으로 관리하는 커넥션 풀 구현체. 
- **스프링 부트(Spring Boot)**에서는 기본 내장 풀로 HikariCP를 씁니다. (2.x 이후 기본값)

### 왜 HikariCP가 유명해??

- 빠르다.
	- 불필요한 동기화, 기능을 줄여서 성능을 끌어올림
- 가벼움
	- 코드가 간결하고 불필요한 옵션이 적다.
- 안정성
	- 오래된 커넥션 교체, 장애 감지 기능이 잘 되어있다. 
- 스프링과 기본 통합되어있어서
	- 스프링 부트는 `spring.datasource.hikari.*` 설정만 하면 바로 사용 가능.


### 동작방식

- 애플리케이션 시작시 DB 커넥션 미리 몇개 만들어둔다. 
- 요청이 들어오면 풀에서 커넥션을 빌려준다.
- 다 쓰면 실제로 연결을 끊는게 아니라 다시 풀에다가 반환시킨다. 
- 오래된건 자동으로 교체되게끔한다. 
- 풀에 커넥션이 다 차면 요청은 대기열에서 connectionTimeout 까지 기다린다.
