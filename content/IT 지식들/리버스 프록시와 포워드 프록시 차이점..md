
### 포워드 프록시(Forward Proxy)

![](https://i.imgur.com/btU0Svk.png)


- 사용자의 실제 IP의 주소가 숨겨진다.
- 프록시 서버의 IP 주소가 대신 사용된다. 
>익명성 제공!!!! 

- 캐싱을 통해서 네트워크 성능 향상. 
	- 자주 사용되는 웹 페이지나, 파일을 프록시 서버에 저장해두면 동일한 요청 빠르게 처리 가능. 


### ## 리버스 프록시(Reverse Proxy)

![](https://i.imgur.com/0zNa4C1.png)

- 로드 밸런싱을 해준다!!!
	- 다수의 백엔드 서버로 트래픽을 분산시켜서 서버 과부하를 방지, 고가용성 유지.
- 외부에서 직접 백엔드 서버에 접근하지 못하게 해서 DDos 공격이나 해킹 방지. 
- SSL 종료라는 중요한 기능이 있다. 
	- SSL/TLS 암호화를 리버스 프록시에서 처리.
	- 그렇게 서버의 부담을 줄이고 중앙에서 인증서 관리를 한다.
