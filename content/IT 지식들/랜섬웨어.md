


### 랜섬웨어란??

- 사용자, 기업의 파일을 암호화하거나 시스템을 잠그고, 몸값(랜섬)을 요구하는 악성코드 
- 파일을 훔친 뒤 유출을 하겠다고 협박하는 방식이 흔하다. 

![](https://i.imgur.com/aXorJ22.png)

### 어떻게 들어와?? 

- 1. 초기 침투
	- 피싱 이메일
	- 원격 데스크톱
- 2. 실행
	- 스크립터 로더로 페이로드 적재.
	- 자동실행 프로그램에 등록한다(서비스, 작업 스케줄러, 레지스트리)
- 3. 권한 상승
	- 자격증명 탈취(메모리, 캐시, 도메인 등등)
- 4. 방해공작
	- 백업/보안 서비스 중지, 복구 기능/부팅 설정 변경. 
- 5. 데이터 유출
	- 민감한 데이터를 압축하고 암호화.
