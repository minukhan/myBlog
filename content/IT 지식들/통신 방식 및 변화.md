

|**통신 방식**|**IPv4**|**IPv6**|**특징 및 역할**|
|---|---|---|---|
|**유니캐스트 (Unicast)**|O|O|**1:1 통신**. 가장 일반적인 통신 방식으로, 특정 출발지에서 **단일 목적지**로 패킷을 전송합니다.|
|**멀티캐스트 (Multicast)**|O|O|**1:다수(그룹) 통신**. 하나의 출발지에서 특정 그룹에 속한 **다수의 목적지** 모두에게 패킷을 전송합니다. (예: IPTV, 화상 회의)|
|**브로드캐스트 (Broadcast)**|**O**|**X (사라짐)**|**1:전체 통신**. 로컬 네트워크 내 **모든 호스트**에게 패킷을 전송합니다. 네트워크 효율 저하 및 보안 문제로 IPv6에서는 폐지되었습니다.|
|**애니캐스트 (Anycast)**|제한적 구현|**O (공식 도입)**|**1:최근접(가장 가까운) 통신**. 동일한 주소를 가진 **다수의 서버 중 라우팅 경로상 가장 가까운 하나**에게 패킷을 전송합니다.|

### IPv4 통신방법

- 유니캐스트
	- 1:1 통신
	- 가장 일반적인 통신
	- 특정 출발지에서 단일 목적지로 패킷을 전송 
- 멀티캐스트 
	-  1: N 통신 
	- 하나의 출발지에서 특정 그룹에 속한 다수에게 패킷 전송
- 브로드 캐스트
	- 1 : N 통신
	- 로컬 네트워크 내에 있는 모든 호스트들에게 패킷 전송.
	- 그룹도 아님 그냥 다 보냄.

### IPv6 통신방법

- 유니캐스트
	- 1:1 통신
	- 가장 일반적인 통신
	- 특정 출발지에서 단일 목적지로 패킷을 전송 
- 멀티캐스트 
	-  1: N 통신 
	- 하나의 출발지에서 특정 그룹에 속한 다수에게 패킷 전송
- 애니캐스트
	- 1: 가장 가까운 통신
	- 동일한 주소를 가진 다수의 서버중에서 가장 가까운 하나에게 패킷 전송. 
	- 결국 1:1 통신임. 만약 여러개있으면 가장 가까운거랑 통신.


### IPv4 브로드캐스트의 폐지된 이유.

- 네트워크 비효율성 :
	- 브로드 캐스트는 로컬 네트워크 모두 보내기 떄문에 CPU 자원을 사용해서 전체 성능 저하.
- 보안문제 : 
	- 로컬 네트워크 내 모든 장치가 패킷을 수신. 
- 대체 수단의 강화 :
	- IPv6에서는 멀티캐스트를 매우 정교하게 설계함.
	- 브로드캐스트가 담당하던 역할을 효율적으로 멀티캐스트로 처리할 수 있게되었음.
