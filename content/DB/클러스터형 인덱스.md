
### 클러스터형 인덱스란?? 

- 비클러스터형 인덱스 : 
	- 일반적인 인덱스는 인덱스와 실제 데이터가 분리되어있다. 
	- 인덱스는 데이터의 위치를 가리키고 실제 대이터는 별도의 공간에 있음. 

- 클러스터형 인덱스 : 
	- 인덱스 자체가 데이터를 포함하고있음. 
	- 리프노드에 실제 데이터가 있다. 
	- 인덱스의 순서에 따라서 데이터가 실제로 정렬되어 저장됨. 

### 어떻게 저장되고 정렬되나??

- 클러스터형 인덱스는 B+ 트리와 같은 자료구조를 사용.
- 그래서 데이터를 정렬하고 저장한다.
- 이 자료구조는 효율적인 검색과 빠른 범위 조회를 지원.
