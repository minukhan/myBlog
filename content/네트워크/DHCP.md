
### DHCP란??

- 네트워크에 새로 연결되는 장치에게 IP주소를 비롯한 필수 네트워크 설정 정보를 자동으로 할당하고 관리해주는 프로토콜을 말함. 
- DHCP 덕분에 사용자는 컴퓨터나 스마트폰을 네트워크에 연결 할 때마다 IP주소, 기본 게이트웨이 등의 복잡한 정보를 수동으로 입력하지 않아도 스스로 네트워크 설정을 완료하고 즉시 인터넷을 사용할 수 있는것!!
- DHCP가 없다면, 네트워크 관리자는 모든 장치에 수동으로 IP 주소를 설정해야 하며, 이 과정은 번거롭고 IP 주소 충돌과 같은 설정 오류를 유발

### 그래서 왜 얘는 UDP를 써? 

- 처음엔 속도때문이겠지! 했는데 또 다른 결정적인 이유가 있다!
- 네트워크에 처음 접속하는 클라이언트는 IP주소를 할당받기위해 서버와 통신해야함!
- 근데 IP주소가 없는 상태에서는 IP기반의 통신을 정상적으로 수행할 수 없음!
- TCP는 통신을 시작하려면 양단의 IP주소와 포트 번호가 명확히 정의된 연결을 설정해야함. 근데, 처음에 IP주소를 모르니까 TCP연결을 할 수 없음. 그래서 UDP를 사용한다. 


### DHCP는 어디계층에 속해??

- 기능상 3계층(네트워크)의 설정 정보를 제공하지만 
- 프로토콜 자체는 7계층(애플리케이션 계층)!!

### 어떤 과정으로 이루어지나??

##### DORA 프로세스라고 한다. 

##### Discover
- IP 주소가 없는 클라이언트는 네트워크에 연결되자마자 DHCP 서버를 찾기위해서 전송.
- 이 메시지는 "이 네트워크에 DHCP 서버 있나요? 저 IP 주소가 필요해요"
##### Offer
- 네트워크 내의 DHCP 서버들은 메시지를 수신하고 클라이언트에게 IP 주소와 기타 설정정보들을 담아서 메시지를 보낸다. 
- 보통 유니캐스트로 전달되지만 경우에따라 브로드캐스트로 전송될 수 있다. 

##### Request
- 그러면 클라이언트는 여러개의 승인(DHCPOFFER)을 받을 수 있다. 그 받은 것중에서 하나를 선택. 
- 그리고 자신이 선택한 메시지를 다시 브로드캐스트로 전송한다. 
- 이 의미는 나 이걸로 선택할께! 의미임. 
##### Acknowledge
- 자신의 제안이 수락된 DHCP 서버는 해당 IP주소와 클라이언트의 MAC 주소를 DB에 기록하여 주소를 확정짓는다. 그리고 최종적으로 설정을 완료하라는 의미로 DHCP_ACK 를 클라에게 보냄
- 그리고 클라이언트는 받은다음 해당 IP 주소를 자신의 네트워크 인터페이스에 설정하고 통신을 시작한다!


### IP 이외의 제공해주는 정보 뭐가있어? DHCP가??

- 서브넷 마스크 
	- 클라이언트가 속한 네트워크의 범위를 정의
- 기본 게이트웨이
	- 클라이언트가 외부 네트워크와 통신하기 위해 거쳐야하는 라우터의 IP 주소
- DNS서버 
	- 도메인 이름을 IP 주소로 변환해주는 DNS서버의 주소
- 도메인 이름 
	- 클라이언트가 속한 네트워크의 도메인 이름이다. 
- IP주소 임대 기간
	- 할당된 IP 주소를 사용할 수 있는 시간을 제공. 

### IP 주소 임대 기간이 뭐야?? 

- IP 주소 임대 기간은 클라이언트가 할당받은 IP 주소를 독점적으로 사용할 수 있는 시간을 의미.
- 만료되기전에 사용기간을 연장해야함!
- 가정 및 소규모 사무실
	- 보통 고정적이고 변동이 적어서 임대기간을 길게 설정한다. 
- 공용 WIFI, 대규모 네트워크 
	- 짧은 임대기간으로 설정해서 사용이 끝난 IP주소를 신속하게 회수하여 재사용
> 임대기간 설정은 네트워크 트래픽 감소와, IP 주소 가용성 확보 사이의 균형을 맞추는 작업
> 트레이드오프가 있다.
