
### 서브넷 마스크란?? 

- IP 주소는 `192.168.1.10`과 같이 하나의 숫자 덩어리처럼 보이지만 아니다!
- 하나는 장치가 속한 네트워크를 식별하는 주소(Network Address)
- 다른 하나는 네트워크 내에서 개별 장치를 식별하는 주소(Host Address)

![](https://i.imgur.com/QLR8iDs.png)


- 서브넷 마스크는 이 IP주소에서 어디까지가 네트워크 주소고, 어디부터가 호스트 주소인지를 구분해주는 32비트 값.

- 서브넷 마스크와 IP 주소를 비트 AND 연산을 하면 네트워크 주소를 추출할 수 있다. 
- **서브넷 마스크** = “어디까지가 같은 네트워크(로컬)인지”를 정함

> [!important] 정리
> 서브넷 마스크는 어디까지가 같은 네트워크를 설정할껀지 정하는것임!!!
> 같은 네트워크면 직접 통신이 가능하게 되고 만약 다른 네트워크면 게이트 웨이를 통해서 통신을 하는 것! 
> ex) 우리 마을을 어디까지 잡을까?? 우리 마을은 나랑 친구야!
> 


### 게이트웨이

- 게이트웨이는 말 그대로 관문 OR 출입문을 의미한다. 
- 게이트웨이 = 라우터라고 보면 될듯. 
- 라우터는 게이트웨이 역할을 한다. <-> 게이트웨이는 라우터에서 실행된다.
- 게이트웨이 주소는 해당 라우터의 IP 주소를 의미한다!!


### 게이트웨이 동작 과정

- 컴퓨터가 다른 장치와 통신을 시작할 때, 목적지 IP와 자신의 IP주소를 서브넷 마스크를 통해 비교한다. 
- 서브넷 마스크로 비교했을때, 같은 네트워크다?? 그러면 바로 직접 통신
- 만약 다른 네트워크라면 패킷을 기본 게이트웨이로 보낸다. 

> [!important] 정리
> 서브넷 마스크는 우리 동네 경계!, 게이트웨이는 다른 동네로 거쳐야하는 마을 이정표.
> 



### VPN이 뭐야???

- VPN(Virtual Private Network)
	- 공개된 인터넷 위에 **가상의 사설망**을 만드는 기술
- 다른 네트워크를 생성해서 그걸로 연결하는 기술. 
	- 인터넷 위에 가상의 전용선(네트워크)를 깔아서 그 네트워크를 통해 바로 연결되도록 하는 기술을 말함. 
- VPN은 터널링 + 암호화를 이용해서 데이터를 암호화한다. 
- 회사나 기관 내부망에 외부에서 안전하게 접속 가능하다. 
- 하지만 단점으로 속도가 느리고, VPN서버가 다운되면 전체가 접속 불가능해진다. 

### NAT(Network Address Translation) 이 뭐야?? 

- 흔히 보는 공유기! 이것도 라우터임. 
- 공인 IPv4 주소는 43억개로 한정되어있어서 주소 고갈 문제에 직면. 
- NAT을 사용하면 가정이나 회사 내의 많은 장치들이 각각 사설 IP 주소를 사용하고, 외부와 통신할때만 공유기(NAT)에 할당된 공인 IP 주소로 변환해서 주소 고갈 문제를 완화.


### NAT의 종류 

- 정적 NAT
	- 사설 IP 주소와 공인 IP 주소를 1:1로 고정해서 매핑
	- 네트워크 서버를 외부에서 항상 동일한 공인 IP로 접속해야 할 때 사용. 
- 동적 NAT
	- 여러개의 공인 IP주소를 풀로 만들어둠. 
	- 내부 장치가 외부와 통신할때, 동적으로 공인 IP주소를 할당한다. 
	- 통신이 끝나면 다시 풀에 반납!
- PAT (Port Address Translation) 또는 NAPT
	- 가장 널리 사용되는 방식
	- 하나의 공인 IP 주소와 여러개의 포트번호를 조합해서 사설 IP 주소를 매핑. 
	- 그리고 그 매핑한걸 테이블에 기얽해서 외부에서 응답이 오면 그걸 가지고 적절하게 전달해주는 방법. 

### 서브넷 마스크의 표현방식?? 

- 서브넷 마스크를 표현하는 방식은 2가지 방법이 있음. 

- 점으로 구분된 십진 표기법 

	- 이진수: `11111111.11111111.11111111.00000000`
	- 십진수 변환: `255.255.255.0`
	- 가장 일반적인 방식

- CIDR (Classless Inter-Domain Routing) 표기법

	- 현대 네트워크에서 사용되는 간결하고 유연한 방식 
	- `192.168.1.10/24`는 서브넷 마스크의 앞 24비트가 `1`임을 의미하며, 이는 `255.255.255.0`과 동일합니다.
	- `10.0.0.5/8`은 서브넷 마스크의 앞 8비트가 `1`임을 의미하며, 이는 `255.0.0.0`과 동일합니다.


### 그러면 255.0.255.0 같은 서브넷 마스크도 가능?? 

- 이론적으로는 표현이 가능. 
- 그러나 실제 네트워크 환경에서 사용되지 않으며 표준 규약에 어긋나는 비정상적인 설정. 

- 서브넷 마스크의 근본적인 규칙은
	- IP 주소를 연속된 네트워크 부분과, 연속된 호스트 부분을 2개로 나누는 것!!

`255.0.255.0`을 이진수로 변환하면 다음과 같습니다: 

```
`11111111.00000000.11111111.00000000`
```
- 이처럼 `1`과 `0`이 번갈아 나타나는 **비연속적인(non-contiguous) 서브넷 마스크**는 표준을 위반
